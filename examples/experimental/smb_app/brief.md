# Northwind Bikes quote app

Create a tiny browser app for a bike repair shop that shows a quote for a
customer. The page must show the title `Northwind Bikes`, two line items named
`Setup` and `Monthly support`, and a visible total of `$198.00`.

Keep the app dependency-free. Use one browser module and one Node built-in test
module. Do not call a network service, use a framework, or add authentication.
